# EBank — Systèmes Distribués et DevOps

Projet de synthèse de Marouane Mounir, II-BDCC, ENSET Mohammedia. Encadrant : Professeur Mohamed YOUSSFI.

| Partie | Mise en œuvre | Guide |
|---|---|---|
| 1 — Microservices | Spring Cloud Config, Eureka, Gateway, OpenFeign et Resilience4j | [Démarrage et recette REST](docs/partie-1.md) |
| 2 — Agent et MCP | Outils MCP, Spring AI, REST, Telegram et Discord | [Configuration et recette](docs/partie-2.md) |
| 3 — Angular | Comptes, formulaire et chatbot Markdown avec flux SSE | [Interface et streaming](docs/partie-3.md) |

Prérequis : Java 21, Maven 3.9+, Node.js 22.12+ ou 24 pour l’interface, et une clé OpenAI pour le chatbot. La collection [Postman](postman/EBank.postman_collection.json) rassemble les requêtes REST.
